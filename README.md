# 📊 Автоматизированный парсер веб-ресурсов и обогащения баз данных (`parserDbWebCp`)

![Python](https://shields.io)
![Selenium](https://shields.io)
![Pandas](https://shields.io)
![MySQL](https://shields.io)
![Excel](https://shields.io)

Комплексное решение на Python для автоматического сбора данных с веб-порталов, их валидации, обогащения записей в базе данных MySQL и формирования готовых аналитических отчетов в формате Excel (`.xlsx`).

> **Примечание:** Проект разработан для автоматизации рутинного сбора геоданных и статусов объектов. Архитектура легко адаптируется под любые веб-источники, каталоги, маркетплейсы и структуры баз данных.

---

## 🎯 Решаемые задачи и возможности

* **Сбор данных с динамических сайтов (Web Scraping):** Эмуляция действий реального пользователя в браузере (Selenium + YandexDriver) для обхода базовых ограничений и корректной загрузки JS-контента.
* **Интеграция с базами данных (SQL):** Автоматический поиск неполных или устаревших записей в MySQL и их точечное обновление спарсенными данными.
* **Очистка и нормализация данных:** Обработка больших массивов строк, приведение форматов к единому стандарту и агрегация с помощью библиотеки `pandas`.
* **Парсинг файлов и метаданных:** Дополнительные модули для извлечения координат из XML-файлов, проверки кодировок `.xlsb` и анализа объема PDF-документов на сервере.
* **Гибкая настройка без правки кода:** Все целевые ссылки, CSS/XPath-селекторы, SQL-запросы и параметры авторизации вынесены в отдельные конфигурационные файлы.
* **Работа по расписанию и логирование:** Готовые скрипты (PowerShell / Batch) для фонового запуска через Планировщик задач Windows с подробной записью логов каждой сессии.

---

## 🛠 Технологический стек

* **Язык:** Python 3
* **Веб-парсинг:** Selenium WebDriver (YandexDriver)
* **Обработка данных:** Pandas, OpenPyXL, XML-парсеры
* **Базы данных:** MySQL (`mysql-connector-python`)
* **Автоматизация и DevOps:** PowerShell (`.ps1`), Windows Batch (`.bat`), Bash (`.sh`), `python-dotenv`

parserDbWebCp/
├── scripts/                      # Вспомогательные модули и проверки окружения

│   └── check*.bat                # Скрипты диагностики Python, браузера и драйвера
├── parserCp.py                   # Главный скрипт: сбор данных с сайта и обогащение БД

├── startParserCp.ps1             # Скрипт автозапуска с ведением журнала логов
├── requirements.txt              # Список необходимых Python-библиотек
└── .gitignore                    # Исключение конфиденциальных данных из репозитория

## ⚙️ Быстрый старт и настройка

### 1. Установка зависимостей
Клонируйте репозиторий и установите необходимые библиотеки:
```bash
git clone https://github.com
cd parserDbWebCp
pip install -r requirements.txt
```

### 2. Настройка драйвера браузера
Для работы Selenium требуется драйвер, соответствующий версии вашего браузера:
1. Скачайте актуальную версию с [YandexDriver Releases](https://github.com).
2. Укажите путь к драйверу в конфигурации или системной переменной `PATH` (для проверки можно запустить `scripts/checkYandexDriver.bat`).

### 3. Конфигурация окружения
В целях безопасности файлы с доступами исключены из репозитория. Перед запуском создайте в корне проекта:

* **Файл `.env`** — для хранения чувствительных данных:
  ```env
  DB_HOST=localhost
  DB_USER=your_username
  DB_PASSWORD=your_password
  DB_NAME=your_database
  ```
* **Файл `config.json`** — для настройки логики сбора:
  * `Link PO` — целевые URL-адреса страниц.
  * `Tegs` — HTML-теги и селекторы нужных элементов.
  * `querry` — SQL-запросы для выборки записей, требующих обновления.

## 🚀 Запуск

* **Ручной запуск:**
  ```bash
  python parserCp.py
  ```
* **Автоматический запуск по расписанию (Windows):**
  Настройте задачу в *Планировщике задач Windows* на запуск файла `startParserCp.ps1`. Скрипт автоматически выполнит парсинг и сохранит статус выполнения, время старта и возможные ошибки в лог-файл.
