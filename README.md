Автоматизированный скрипт для сбора, обогащения и валидации данных из базы данных MySQL и веб-ресурсов («Барс»/«Рдб») с последующей выгрузкой отчетов в Excel. Проект поддерживает запуск по расписанию и логирование сессий.

## 🚀 Основной функционал

1. **Извлечение данных:** Скрипт находит записи с незаполненными полями в базе данных MySQL.
2. **Веб-парсинг (Scraping):** Обращается к сайту «Барс»/«Рдб» для автоматического определения географических координат и признаков УЦН (Устранение Цифрового Неравенства).
3. **Обработка данных:** Агрегирует полученную информацию с помощью библиотеки `pandas` в единый структурированный DataFrame.
4. **Экспорт:** Формирует и сохраняет финальный отчет в формате Excel.

> ⚠️ **Важное замечание по коду:** Блок пакетной обработки файлов (`for file in listFiles: ...`) намеренно временно закомментирован в `parserCp.py` из-за введенных лимитов на объем данных. Это позволяет контролировать потоки информации напрямую в ручном или полуавтоматическом режиме.

## 🛠 Требования и окружение

Для корректной работы парсера необходимо установить и настроить внешние компоненты:

1. **Яндекс Браузер и YandexDriver:** 
   Для симуляции действий пользователя (веб-скрейпинга) требуется скачать подходящую под вашу версию браузера версию драйвера.
   * Ссылка на релизы: [YandexDriver Releases](https://github.com/yandex/YandexDriver/releases)

2. **Зависимости Python:**
   Убедитесь, что у вас установлены библиотеки `pandas`, `mysql-connector-python`, `selenium` (или аналогичная для управления YandexDriver), `openpyxl` (для работы с Excel) и `python-dotenv`.

## 💻 Запуск проекта

### Локальный ручной запуск
Вы можете запустить процесс напрямую через Python:
```bash
python *.py
```

### Автоматический запуск по расписанию (PowerShell)
Для планирования задач (например, через *Планировщик задач Windows*) используйте скрипт `start*.ps1`. 

Данный скрипт:
1. Инициирует запуск `*.py`.
2. Записывает событие, дату, время и статус процедуры в локальный лог-файл для последующего аудита.
